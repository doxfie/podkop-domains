# podkop-domains

Список доменов для [Podkop](https://podkop.net/) — точечной маршрутизации на OpenWrt.
Перечисленные сервисы ходят через VPN, весь остальной трафик идёт напрямую.

## Список

Нажмите кнопку копирования в правом верхнем углу блока:

## Куда вставить

1. Веб-интерфейс роутера → `Сервисы` → `Podkop`.
2. **Тип пользовательского списка доменов** → `Текстовый список`.
3. Вставить скопированное в поле **Список пользовательских доменов**, заменив то, что там было.
4. `Сохранить и применить`.

## Вариант получше: обновляться автоматически

Тогда список не придётся копировать заново после каждого изменения — роутер сам будет
забирать свежую версию. В поле **Внешние списки доменов** добавьте ссылку:

```
https://doxfie.github.io/podkop-domains/domains.lst
```

Периодичность задаётся в общих настройках Podkop: `1h` / `3h` / `12h` / `1d` / `3d`.

> Если список не обновляется — скорее всего, роутер не может достучаться до GitHub.
> Лечится галкой «загружать списки через прокси» в настройках Podkop: тогда список
> скачивается через сам туннель.

## Как это работает

Podkop добавляет каждую запись как `domain_suffix`, то есть **домен покрывает все свои
поддомены**: `whatsapp.com` — это и `web.whatsapp.com`, и `faq.whatsapp.com`, и всё
остальное. Поэтому в списке только «корни». Конкретные поддомены оставлены там, где
родительский домен общий или многоарендный и захватывать его целиком нельзя — такие
строки помечены комментарием.

Строки, начинающиеся с `//`, и пустые строки игнорируются. Комментарий должен быть на
отдельной строке: `example.com // текст` не пройдёт валидацию и домен потеряется.
Домены — только в нижнем регистре.

## Правка списка

Единственный источник правды — [`domains.lst`](domains.lst). Код-блок выше между
маркерами `domains:start` / `domains:end` подставляется автоматически: после пуша
в `main` воркфлоу [`sync-readme`](.github/workflows/sync-readme.yml) переписывает
README под содержимое `domains.lst`. Руками блок не трогать — перезатрётся.
